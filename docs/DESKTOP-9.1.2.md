# Agent Zero on screen

Agent Zero now moves in the conversation header in both Chat and Code. The artwork comes from the ZERO avatar pack supplied by the TalkToAi maintainer.

- Send a message to wake Zero. The portrait cuts to Zero’s hands typing as reply text streams into the conversation.
- In Code, the header shows the current tool, the model step when available, and elapsed time. It distinguishes writing or building from waiting for a tool or project reviewer.
- A finished reply or completed task triggers a brief animation. A stopped run, interrupted reply, or request for your input has its own status.
- Choose **Pause motion** for a still portrait. TalkToAi saves your choice and stops animating while its window is minimized or hidden.

The portrait is silent and bundled with the app. The moving frames come from the pack’s dark idle, waking, working, creation, and milestone clips. The desk close-up focuses on the typing hands and keyboard.
