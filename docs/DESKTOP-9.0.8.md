# TalkToAi Code 9.0.8

## Finish a project from Chat or Code

Ask “Make me an interactive generative art page.” Agent Zero can use the selected project directly, recover from an unsuccessful tool call and save a standalone deliverable. If a local model keeps describing a file it plans to make, TalkToAi can request its contents, create the new file, verify it, and register it under **Evidence**. The result distinguishes a structural check from a browser test. A follow-up such as “try harder” can resume the unfinished project.

The Windows installer and Store package include Python 3.14 and pip for project scripts. TalkToAi first checks for a working project environment and installed Python. The bundled interpreter keeps dependencies installed by pip in the current project. Source and portable installations use their available Python. Shell and file tools run as the signed-in user in Act mode. Plan mode remains available for read-only work. Changes to protected system locations are subject to the operating system’s permissions.

## Ask about a long filing

Attach a selectable-text PDF or SEC filing in HTML and ask a question. TalkToAi indexes the text on this device and selects passages for the current model window. PDF labels refer to the PDF viewer's page number. You can ask about a specific page, item, exhibit, or the back half in a later message. The source index stays on the device that received the attachment.

For a closer reading, say **“Review the entire filing. Summarize the risks and identify who signed the final certification. Cite the PDF pages.”** Agent Zero reads the indexed passages in batches and saves the completed notes locally. If a run stops, send **“Resume the review”** in the same conversation using the same model. Full reviews take several model calls. Ordinary questions retrieve selected passages in a single reply.

Attach up to five documents of 32 MB each. Selectable PDFs can contain up to 600 pages, with a limit of three million extracted characters per document. Scanned pages need OCR. The attachment display shows how many PDF pages contained text.

## Search and create agents in Chat

Ask a current public question in ordinary Chat to search the web and receive links. The app supplies the search results to the selected model, so models without function calling can use them. Search availability depends on the network and search service.

Type **“Create an agent named Atlas to explain scientific papers in plain language”** to save a specialist. Use **Agents…** beside the specialist selector to edit or remove it. For separate perspectives on a project, try **“Create three agents to review my code, tests and documentation.”** Agent Zero coordinates up to three read-only project reviewers on a compatible local model.
