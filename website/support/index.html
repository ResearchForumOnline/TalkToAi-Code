Contact and issue reports

Email shaf@talktoai.org or open a GitHub issue. Include the app version, Windows version, what you expected, what happened, and reproducible steps. Do not post API keys, passwords, private files, server addresses, personal data or full logs publicly. Send security-sensitive reports by email rather than a public issue.

Before troubleshooting

Local models and game engines are separate installations. API use requires your own provider account and key; charges and quotas are set by that provider. Test a small project first, keep a backup, and review agent edits. A check that exits successfully is not proof of complete game testing.
