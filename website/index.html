Chat when you want to talk. Code when you want to build.

Separate Chat and Code sections keep conversations easy to find. Describe a coding result, steer the agent as it works, then inspect the changes and evidence.

01 / FIND YOUR WORK

Chat. Code. Pin. Archive.

Keep general chats and coding tasks in their own sidebar sections. Search messages, project names and drafts; pin important chats and archive the rest without deleting them. Task kind and chat organization persist across restarts.

02 / KEEP CONTEXT

Project memory & recovery

Save decisions, conventions and test commands as editable project notes. Drafts autosave, and chat history retains a validated previous-save recovery copy.

03 / ASK FOR THE OUTCOME

Tools on demand. Saved steps.

The agent can load additional tools as the task develops, maintain a saved checklist and continue after output limits within a bounded budget. Steps separates model-reported progress from check-runner evidence.

04 / WORK ACROSS MACHINES

Your own SSH connections

Ask the agent to discover saved host aliases, verify the connection and inspect your remote project. OpenSSH keeps your keys on your computer; no shared TalkToAI server is included.

05 / CHECK THE RESULT

Coding & Game Lab

File edits, diffs, checkpoints, tests, browser interaction and screenshots. Open the bundled Score Arena example as your own editable project. Godot and Blender are separate installations; Unity commands depend on your project.

06 / STAY IN CONTROL

Updates, tray & shortcuts

Check GitHub and download a SHA-256 verified installer inside the app. You choose when to install. Enable Start with Windows for tray startup, or launch from Desktop or Start.

No tool vocabulary needed

Start with what you want to happen.

Open a Code task, choose your model, and ask in ordinary language. Help me start offers editable examples. Plan keeps inspection read-only; Act permits edits and commands using your account. Watch the actual invocations in Tools, then review Changes and Evidence.

Find and repair

“Find my NIGHTFALL game on Desktop, fix its menu, and check it runs.” TalkToAi narrows project candidates by folder names and markers; Godot's app name may distinguish the native project. If several match, choose one before changes.

Make a game

“Make a playable game about a haunted station.” The agent can inspect the workspace, consult public engine docs, build a bounded playable loop, and report launch steps and playtesting gaps.

Use my server

“Connect to my saved server and inspect my app.” It can verify an existing OpenSSH alias and inspect the remote folder. You handle missing host setup, passwords and two-factor prompts.

Research, then build

“Research this option, then build it in my app.” It can use a bounded chain of read-only observations before an Act-mode change, with each result shown in Tools. A chain uses existing permissions and stops on an error or cancellation.

Public automatic searches use generic topic queries; say “offline” to skip them. Project context and tool results are sent to the model route you select. The model, installed development tools and checks determine what it can actually finish.

Know what you’re getting.

Do I need a paid AI subscription or a GPU?

The application does not require an app subscription. Local and self-hosted inference use your own hardware; CPU inference is supported, but speed and model quality depend on your RAM, processor and selected model. There is no promise of cloud-model performance on a low-powered PC. Optional API providers have their own quotas and prices.

How does the optional OpenAI API work?

Open More → API providers → OpenAI API, enter your own key or reference an environment variable, and explicitly choose the provider. The app supplies no API key, credit or subscription. A per-response token limit is not a spending cap. Auto never silently falls back to OpenAI.

Can it connect to my server automatically?

In Act mode, ask it to connect using an existing SSH host alias and inspect a named project. The agent can discover aliases and test the connection before using remote tools. Password-only accounts, first-time host verification and missing SSH configuration need normal interactive setup. Plaintext password files are not imported into model context.

What is saved, and what is sent to an AI provider?

Chats and settings are stored locally in your operating system user-data folder. Project memory, playbooks and experiment records live in the selected project under .talktoai-code. A remote/API model receives the task context and any notes or tool results used in a request. If you connect mail, selected message content can be sent to the model you choose for a mail task. Don’t put passwords in chats or project memory. A previous-save chat backup is not a substitute for normal project and off-device backups.

Does the app update itself without asking?

No. On Windows, open About & updates to check GitHub, read release notes and download a verified installer. Linux and macOS source installations update by downloading a newer source release and rerunning the platform script. You choose when to install.

What about ZeroThink, Linux and macOS?

More → Link ZeroThink account opens the optional account-link flow. Vault inference remains experimental and account/provider entitlements still apply. Windows has a packaged installer. Linux and macOS use source installers that create per-user virtual environments; installer and offscreen GUI startup passed on clean Ubuntu and macOS runners; interactive use still needs confirmation. Windows accessibility PC Pilot is Windows-only.

Is it guaranteed to build or test an entire game?

No. This is a desktop application with practical development tools, not a guarantee of correct code, full gameplay coverage or parity with any hosted assistant. Models can make mistakes. Review changes and distinguish automated import/build checks from actual gameplay testing.
