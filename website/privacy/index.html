Privacy policy for TalkToAi Code

Effective 23 September 2026. TalkToAi Code is a local-first desktop coding assistant from TalkToAI. This policy describes the app, not every other TalkToAI service. For the broader site, see the TalkToAI privacy policy.

What stays on your computer

The app saves conversations, settings, drafts, connection aliases and selected-provider preferences under your Windows user profile. Editable project memory and screenshots or other evidence may be saved inside the project you choose. The app may read or change project files and operate tools on your computer when you request it in Act mode. Uninstalling the app may leave user data and projects in place so you do not lose them; you can remove those separately.

What can leave your computer

Your chosen model destination matters. Local models process requests on your computer. A self-hosted server, ZeroThink vault route or third-party API receives the prompts, project context, selected file contents and tool results sent to that route. An API provider may process and retain data under its own terms. The app does not silently switch Auto to a paid API. Optional GitHub update checks contact GitHub. Browser tools open sites you request, which can receive ordinary web traffic. SSH tools connect to hosts you select.

Keys and connected accounts

API keys may be kept only for the session, read from an environment variable, or—if you opt in—stored using Windows user encryption. They are used to authenticate to the provider you select. ZeroThink account linking is optional and uses its own service and account. Do not put passwords, secrets or sensitive personal information in chats or project memory, as those contents may be sent to a selected remote model.

Your choices and retention

You choose the project, model route, whether to link external accounts, and whether to enable desktop or SSH tools. Local history and project files remain until you remove them. Remote providers and websites apply their own retention policies; TalkToAI cannot delete copies held by a provider you chose. Review the provider's policy before sending sensitive work. You can request help with data or privacy questions using the contact below.

Security and limits

The app runs tools with your signed-in user's permissions; it is not an operating-system sandbox. Screenshots can capture visible private material. Close unrelated sensitive windows before using computer or screenshot tools, review changes before publishing, and maintain normal backups.

Contact

TalkToAI privacy contact: shaf@talktoai.org. For app support and security reports, see TalkToAi Code support.
